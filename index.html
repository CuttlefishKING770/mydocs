    这是关于如何使用 Markdown的方法

    1. 标题 (控制字号大小)

    就像写大纲一样，用井号 “#” 的数量来决定层级。

    语法：# + 空格 + 文字

    一级标题 (通常用作文章的大标题，最大)

    二级标题 (章节名，比如“第一章：玄州”)

    三级标题 (小节名，比如“1. 地理环境”)

    2. 换行与段落

    这是新手最大的痛点。在 Markdown 里，按一下回车不叫换行，叫空格。

想要换一行（另起一段）： 👉 按两次回车（中间空一行）。 效果：段落之间会有明显的间距。

想要紧凑的换行（比如歌词、诗句）： 👉 在上一行的末尾敲两个空格，再按回车。 效果：行与行之间挨得很紧。

    # 3. 代码块 (你的笔记神器 💻)

    这就是刚才让你笔记里的命令变成“灰色方框”的魔法。它能保留格式，不会乱跑。

    单行代码（比如穿插在文字里的命令）： 用两个反引号 ` 包起来。

    输入：请执行 pip install 命令。 显示：请执行 pip install 命令。

    多行代码块（比如一整段配置）： 用三个反引号包裹首尾。

    git init git add . ```

    (注：反引号 ` 通常在键盘左上角 Esc 键的下面，要用英文输入法打)

    4. 列表 (整理思路)

    无序列表 (小圆点)：用减号 - 或星号 * 加空格。

    • 记得买菜 - 记得写日记

    有序列表 (数字)：直接写 1. 加空格。

    1. 第一步 2. 第二步

    2. 引用 (给自己留的话) 如果你想对某段话做个高亮，或者引用别人的名言。

    语法：> + 空格
