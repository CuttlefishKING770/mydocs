这是关于如何使用 Markdown的方法

# 1. 标题 (控制字号大小)
就像写大纲一样，用井号 “#” 的数量来决定层级。

语法：# + 空格 + 文字

# 一级标题 (通常用作文章的大标题，最大)  
## 二级标题 (章节名，比如“第一章：玄州”)  
### 三级标题 (小节名，比如“1. 地理环境”)

![baiot](images/标题写法.jpg)   
# 2. 换行与段落

在 Markdown 里，按一下回车不叫换行，叫空格。
（回车↩︎）   
想要换一行（另起一段）： 👉 按两次回车（中间空一行）。  
 效果：段落之间会有明显的间距。

想要紧凑的换行（比如歌词、诗句）： 👉 在上一行的末尾敲两个空格，再按回车。   
效果：行与行之间挨得很紧。

# 3. 代码块 (固定格式类似pdf)
让你的命令和代码像程序员文档一样显示在“灰色方框”里，保留格式，不会乱跑。

### 1. 单行代码 (穿插在文字里)  
**语法**：用两个反引号 \` 把内容包起来。  
**效果**：输入 `pip install` 就可以安装。

### 2. 多行代码块 (一整段配置)
**语法**：在首尾各写 **三个反引号**  

````markdown
```bash
git init
git add .
git commit -m "第一次提交"
```
````
(注：反引号 ` 通常在键盘左上角 Esc 键的下面，一定要用**英文输入法**打) 

# 4. 特殊格式


### 无序列表 (小圆点)
语法：用减号 `-` 或星号 `*` 加空格。

- 记得买菜
- 记得写日记

### 有序列表 (数字)
语法：直接写 `1.` 加空格。

1. 第一步
2. 第二步

### 引用 (给自己留的话)
如果你想对某段话做个高亮，或者引用别人的名言。
语法：`>` + 空格

> 这是一个引用的样式

# 6. 强调 (加粗与斜体)
写小说设定时，总有些关键词需要醒目一点。

- **加粗**：用两个星号包裹。
  - 语法：`**重点文字**`
  - 效果：**重点文字**
- *斜体*：用一个星号包裹（通常用于内心独白或特殊术语）。
  - 语法：`*内心独白*`
  - 效果：*内心独白*
- ~~删除线~~：用两个波浪号包裹（用于吐槽或废弃的旧设定）。
  - 语法：`~~旧设定~~`
  - 效果：~~旧设定~~

# 7. 超链接 (跳转)
MkDocs 的核心优势就是可以互相跳转。

- **外部链接** (跳转到百度/谷歌)：  
  语法：`[显示文字](网址链接)`  
  效果：[百度一下](https://www.baidu.com)

- **内部链接** (跳转到你自己的其他文档)：   
  语法：`[文字解释](具体路径)`    
  效果：[python学习跳转](python_study.md)   
  *(注：括号里写你 docs 文件夹下的文件名，支持相对路径)*

# 8. 表格 (二维表格)
虽然 Markdown 的表格语法看起来有点麻烦，。

语法结构：
```
| 角色名 | 门派 | 境界 |
| :--- | :--- | :--- |
| 张三 | 玄天宗 | 筑基期 |
| 李四 | 散修 | 金丹期 |
```
语法效果：
| 角色名 | 门派 | 境界 |  
| :--- | :--- | :--- |  
| 张三 | 玄天宗 | 筑基期 |  
| 李四 | 散修 | 金丹期 |  

*(注意：第二行的 `| :--- |` 是必须的，用来分割表头)*

# 9. 提示块 / Admonitions (MkDocs 的魔法 ✨)
这是 MkDocs 主题（Material Theme）最漂亮的功能，能生成带颜色和图标的提示框，非常适合写“注意事项”或“备注”。

语法：(三个感叹号 + 空格 + 类型)

!!! note "备注"
    这里是备注的内容，前面必须缩进（按Tab键或4个空格）。
    如果不缩进，框框就会断掉，变成普通文字。


!!! warning "警告"
    这是一个警告框，颜色通常是黄色的。

*(常用类型还有：`info` 蓝色, `success` 绿色, `tip` 青色, `failure` 红色)*
``` 
MkDocs 默认不开启这个“魔法”功能，你需要去“总控室” mkdocs.yml 里手动把开关打开。
请按照以下步骤操作：
1. 打开 mkdocs.yml 文件
找到你项目根目录下的 mkdocs.yml 文件（就是你设置网站名字的那个文件）。
2. 粘贴配置代码
你需要添加一个 markdown_extensions 模块。请把下面这段代码完整复制，粘贴到 mkdocs.yml 的最末尾：

markdown_extensions:
  - admonition
  - pymdownx.details
  - pymdownx.superfences

3. ⚠️ 重要：重启服务
修改配置文件（mkdocs.yml）后，正在运行的预览通常不会自动更新配置。
在你的终端/黑框框里，按 Ctrl + C 停止当前的运行。
重新输入 mkdocs serve 并回车。
再次刷新你的网页，那个漂亮的方框应该就出现了！
简单解释下加的那三行是干嘛的：
admonition: 开启 !!! 这种提示块语法的核心功能。
pymdownx.details: 让你可以使用可折叠的提示块（比如 ??? note "点击展开"）。
pymdownx.superfences: 这是一个增强功能，防止复杂的代码块把你的提示框“撑爆”，建议一并加上
防止以后出错
```
